# Subdog — конструктор комплекту підписок для навчання й роботи

Користувач обирає мету (навчання / робота / і те, і те), роль і сферу — сайт збирає готовий набір сервісів.
Склад можна міняти, а калькулятор показує вартість на місяць і на рік.

## Як запустити

Потрібен лише Windows із вбудованим PowerShell 5.1: ні Node, ні Python встановлювати не треба.

**Режим із сервером (рекомендований)** — справжні акаунти, набори й адмін-права на сервері:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Відкрийте <http://localhost:8080>. Дані лежать у `server-data/` (користувачі, набори, правки каталогу). Пароль адміна: `-AdminPassword "ваш-пароль"` (без параметра діє `admin123` і сервер про це попередить). Інший порт: `-Port 9000`.

**Режим без сервера** — двічі клацніть `index.html`. Сайт сам визначає, що сервера немає, і зберігає акаунти й набори в `localStorage` браузера (дані не виходять за межі цього браузера). Каталог береться з `data/catalog.js`, бо з `file://` браузер забороняє `fetch`.

**Тести:**

- `tests.html` (краще через `serve.ps1`): 37 перевірок логіки, каталогу й браузерної реалізації акаунтів.
- `powershell -ExecutionPolicy Bypass -File test-api.ps1`: 51 перевірка сервера (реєстрація, права, валідація, обмеження, перезапуск). Сам піднімає тимчасовий сервер на порту 8090 і нічого не чіпає у ваших даних.

> Після кожної зміни `data/catalog.json` запустіть `sync-catalog.ps1`. Він перевіряє JSON (унікальні id, набори посилаються на існуючі сервіси) і перегенерує `data/catalog.js`. Тест у `tests.html` попередить, якщо файли розійшлися.

## Правила розрахунку (файл `js/calc.js`)

- Студентська знижка діє лише там, де `studentDiscount > 0`; в інших сервісів ціна не змінюється.
- Рік = 12 × місяць, якщо немає річного тарифу (`yearlyPrice`) або він не дешевший.
- Знижка застосовується й до річного тарифу.
- Командний план: ціна за людину × кількість місць, не менше `team.minSeats` (Claude Team і ChatGPT Business від 2 місць). Для кожного сервісу можна вказати свою кількість ліцензій (`qty`). Якщо в сервісу немає командного плану, за замовчуванням рахується 1 акаунт, але можна додати ще, і кожен платитиме за себе.
- Безкоштовний план дає 0, якщо сервіс його має.
- Порожній набір = 0 і 0.

Демо з завдання (сервіс А 200, сервіс Б 300 зі знижкою 50%): 350 → 4200; без знижки 500 → 6000; без А 150 — усе це є в `tests.html`.

## Розподіл ролей

- **Дизайнер:** логотип у `index.html`, палітра й шрифти в `css/style.css`; макети ще можна накреслити у Figma за готовою версткою.
- **Фронтенд:** `js/app.js` (каталог, фільтри, конструктор, калькулятор) і `js/calc.js`.
- **Бекенд і БД:** `serve.ps1` і `js/api.js`, схема й API нижче.
- **Контент і тестування:** наповнення — `data/catalog.json` (або адмін-панель), перевірка цін — розділ «Ціни», тести — `tests.html` (37) і `test-api.ps1` (51), презентація — розділи «Що вміє сайт» і «Аналоги».

### Бекенд

`serve.ps1` це навчальний сервер для однієї машини (HTTP, однопотоковий): статичні файли плюс JSON API. Дані в `server-data/*.json`.

| Метод і шлях | Права | Що робить |
|---|---|---|
| `POST /api/register`, `POST /api/login` | усі | створює акаунт / вхід, повертає токен сесії (7 днів) |
| `POST /api/logout`, `GET /api/me` | вхід | завершує сесію / поточний користувач |
| `GET/POST /api/sets`, `DELETE /api/sets/{id}` | вхід, лише свої набори | збережені набори |
| `GET /api/catalog-overrides` | усі | правки каталогу, які зробив адмін |
| `PUT/DELETE /api/catalog-overrides` | **admin** | зберегти / скинути правки |

Що зроблено на сервері: паролі PBKDF2-SHA256 (120 000 ітерацій, випадкова сіль), токени сесій, перевірка ролі, валідація всіх вхідних даних (URL лише `http(s)`, ціни ≥ 0, ліміт тіла 1 МБ), обмеження спроб входу (5 невдач за 10 хвилин), заголовки безпеки (CSP, nosniff), `server-data/` і `.ps1` не віддаються як статика.

Для справжнього продакшену потрібні HTTPS, справжня БД, відновлення пароля й підтвердження пошти. Схема таблиць для такого переходу:

```sql
categories(id PK, name, icon)
services(id PK, name, category_id FK, group_id, description, url,
         price_month, price_year NULL, student_discount_pct DEFAULT 0,
         has_free BOOL, free_note, price_source, price_note, price_date DATE)
team_plans(service_id PK/FK, price_month_per_user, price_year_per_user NULL, min_seats DEFAULT 1)
users(id PK, email UNIQUE, name, role CHECK IN ('user','admin'), password_hash, salt)
saved_sets(id PK, user_id FK, name, plan, seats, yearly BOOL, created_at)
saved_set_items(set_id FK, service_id FK, use_free BOOL, qty NULL, PRIMARY KEY(set_id, service_id))
```

### Дизайн-система

Темний «AI» стиль: майже чорний фон із фіолетовим сяйвом, одна світна куля в героя. Без скла, 3D й анімацій, щоб код лишався легким.

- **Код:** без коментарів, класи за БЕМ (`block__element_modifier_yes`), звичайний CSS без `clamp()`, `calc()` і змінних, jQuery із конструкторами й `prototype`.
- **Шрифт:** Manrope (є кирилиця), з Google Fonts; без інтернету працює Arial.
- **Колір:** тло `#0b0618`, акцент `#7c3aed`.
- **Зручність читання:** базовий текст 17 px, елементи для клацання від 44 px, звертання на «ви».
- **Для бізнесу:** командний план із вибором 3 / 5 / 10 / 25 / 50 місць, окремі ліцензії на сервіс і ціна на одну людину.
### Мови

Усі видимі рядки інтерфейсу загорнуто в `T('український текст')`, англійський переклад лежить у словнику `js/i18n.js` (ключ це український текст, параметри `{n}`, множина через `I18n.plural`). Тексти каталогу мають англійські поля: `desc_en`, `freeNote_en`, `priceNote_en` у сервісів, `name_en` у категорій і наборів, `title_en` / `text_en` у майстра, `groups_en` для груп. У адмін-панелі можна вказати англійський опис і примітку (без них показується український текст). Тест у `tests.html` перевіряє, що в англійській частині каталогу немає кирилиці й усе перекладено. Щоб додати ще мову, потрібен новий словник і поля `_xx` в каталозі.
## Ціни: що перевірити перед презентацією

Усі ціни зберігаються й показуються **в доларах США без податків** (`"currency": "USD"` у `catalog.json`). Звірено 17–21.11.2026 за офіційними сторінками сервісів і, де вони не віддали цифр, за сторонніми джерелами. Якщо джерело показує іншу валюту (євро для Google Workspace, гривня для Google One і YouTube Premium), суму перераховано в долари за курсом НБУ на 11.11.2026 (**$1 = 45,50 грн, €1 = 51,08 грн**, поле `rates`), це зазначено в примітці до ціни. В Україні до іноземних цифрових послуг може додаватися ПДВ 20% (за повідомленнями ЗМІ, наприклад ChatGPT), у цифри каталогу він не входить. У кожного сервісу є `priceSource` і `priceNote` (що саме знайдено, українською й англійською), їх видно на картці підписки:
| `priceSource` | Сервіси | Що це означає |
|---|---|---|
| `official` (14) | Todoist, Trello, Obsidian, Google One, Slack, Zoom, Adobe CC, Claude, ChatGPT, Coursera, Proton VPN, 1Password, Bitwarden, Spotify | усі цифри є на офіційній сторінці |
| `partial` (8) | Notion, Google Workspace, Dropbox, Figma, GitHub, Replit, Grammarly, Perplexity | на сторінці є основна ціна, частину (річну, помісячну, командну) не видно |
| `unverified` (7) | Microsoft 365, Teams, Canva, JetBrains, Duolingo, Quizlet, YouTube Premium | офіційні сторінки закриті (403), не відкрились або показують ціни лише через JavaScript; дані зі сторонніх джерел |

Що змінилося порівняно з першою версією: студентські знижки, яких я не зміг підтвердити (Microsoft 365, Canva, Todoist), і командні ціни без джерела (Coursera, Replit, Grammarly, Proton VPN, Obsidian) прибрано. Ціни на Claude, Google One, Microsoft 365, Canva, Zoom та інші виправлено.

Перед показом пройдіть за посиланням кожного сервісу з позначкою `unverified`, виправте ціну й оновіть дату. Адмін-панель ставить дату автоматично, а джерело змінює на «введено адміністратором».

## Чек-лист тестувальника

- [ ] Сума з демо (350/4200, 500/6000, 150) — `tests.html`
- [ ] Порожній набір показує 0
- [ ] Знижка не змінює ціну сервісів без знижки (наприклад, Trello, Slack)
- [ ] Набір лишається після F5 і після закриття вкладки
- [ ] Два сервіси з однаковою роллю (Notion + Obsidian) дають «дублюється», а GitHub + JetBrains ні
- [ ] Командний план: зміна кількості людей міняє суму
- [ ] Фільтри каталогу комбінуються між собою
- [ ] Збережений набір відкривається з акаунта, видалений зникає
- [ ] Звичайний користувач не бачить `#/admin`, а прямий запит до API без прав повертає 403
- [ ] Сайт читається на телефоні (375 px) і не виходить за межі екрана

## Аналоги

Порівняйте Subdog із тим, як ціни зібрано на офіційних сторінках сервісів (кожен показує лише свої плани) і з агрегаторами та трекерами підписок, наприклад Rocket Money або Subscribed.fyi. Актуальність цих сервісів перевірте самі. Різниця Subdog: він не відстежує підписки, які вже є, а **збирає комплект під мету й сферу** і порівнює плани (студентський, командний) в одному місці.

## Відомі обмеження

- **Сервер навчальний:** HTTP без шифрування, одна машина, файлове сховище, сесії лише в пам'яті (після перезапуску потрібно увійти знову). Для публічного сайту потрібні HTTPS і справжня БД.
- **Без сервера** (`file://`) дані лежать у браузері, роль `admin` там можна підробити через консоль, а правки каталогу бачить лише цей браузер.
- **Правки адміна** зберігаються як різниця з `catalog.json` (змінені, додані й видалені сервіси), тому нові ціни з файлу доходять до всіх сервісів, яких адмін не чіпав.
- **Ціни** у доларах без податків (в Україні може додаватися ПДВ 20%), акційні пропозиції (перший рік) не враховані, курс для перерахунку з євро й гривні зафіксований у `rates`. 7 сервісів зі сторонніх джерел треба звірити вручну.
- **Не перевірено:** відкриття з `file://` у реальному браузері (імітував відсутність `fetch` і Web Crypto в Chromium) та робота в Firefox і Safari (додані `-webkit-` префікси, але самі браузери не запускались).
